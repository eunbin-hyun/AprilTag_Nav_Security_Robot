# C207 관제 화면

싸피 공통 프로젝트 C207 보안 로봇의 **관제 대시보드**입니다.

외부 의존이 없는 **단일 HTML 한 장**입니다. 빌드 단계가 없고, `index.html` 을 그대로 nginx 에 얹으면 돕니다.

## 파일

| 파일 | 무엇 |
| --- | --- |
| `index.html` | **유일 정본.** 이 한 장이 화면 전부입니다 |
| `UX-변경기록.md` | 변경 기록. 절 번호로 작업 사이클이 이어집니다 |
| `robot-face-preview.html` | 로봇 마스코트 표정 명세용 별도 미리보기 |

## 왜 React 를 걷었나

07-27 에 만든 React 프로젝트를 07-29 에 전수로 재어 봤더니, 화면 28 파일 1,793 줄 중 손대지 않고 살릴 수 있는 것이 8 개 338 줄(19%)뿐이었습니다. 고쳐 쓰는 비용이 새로 만드는 비용을 넘어서, 08-01 에 단일 HTML 로 다시 만들기로 정했습니다.

지금 이 파일은 그 결정에 따라 만든 화면이고, 실서버 창구에 전부 붙어 있습니다.

## 서버 창구

화면 값은 전부 서버에서 옵니다. 같은 오리진이라 별도 설정이 없습니다.

- 로그인 — `POST /api/auth/login` · `GET /api/auth/me` · `POST /api/auth/logout`
- 첫 화면 — `GET /api/dashboard/snapshot`
- 실시간 — `/ws/dashboard`
- 그 밖 — 알림 확인·처리·신원, 셔틀 호출, 출동 고르기, 긴급 정지, 카메라, 명부, 예보, 대응 통계

주소에 `?mock=1` 을 붙이면 서버 없이 화면 모양만 보는 모드가 켜집니다. **기본은 꺼짐**입니다. 배선 확인이 끝나면 이 스위치를 통째로 지웁니다.

## 배포

빌드가 없으므로 파일 한 장을 올리면 끝입니다.

```bash
scp -i <키> frontend/index.html ubuntu@robot.example.com:/var/www/ssacurity/index.html
```

올린 뒤에는 서버 해시를 대조합니다.

```bash
ssh -i <키> ubuntu@robot.example.com "sha256sum /var/www/ssacurity/index.html"
```

⚠ 젠킨스 자동 배포는 백엔드 전용입니다. 이 화면은 그 파이프라인에 들어가지 않습니다.

## 고칠 때

- `index.html` 한 장이 1MB 라 **줄끝을 건드리면 diff 가 통째로 쓸모없어집니다.** `.gitattributes` 가 `* -text` 로 막고 있으니 풀지 마십시오.
- 고친 내용은 `UX-변경기록.md` 에 절을 더해 남깁니다. 큰 파일이라 덮어쓰지 말고 뒤에 붙여 주십시오.
- 시연 기기 기준 해상도는 **1920×1200** 입니다. 여섯 탭 모두 세로 스크롤이 생기지 않아야 합니다.
