# AprilTag 인쇄용 원본 (tag36h11)

출처: [AprilRobotics/apriltag-imgs](https://github.com/AprilRobotics/apriltag-imgs)
공식 원본(10×10 px)을 NEAREST 확대. 생성 2026-07-31.

## 파일

**v2 를 쓴다.** v1(160 mm)은 실인쇄에서 크기와 종횡비가 틀어졌다 (아래 §왜 v2 인가).

| 파일 | 용도 |
| --- | --- |
| `tag36h11_id{N}_140mm_A4_v2.pdf` | **인쇄용 (현행).** 검은 사각형 140 mm, 검증자 포함 |
| `tag36h11_id{N}_140mm_A4_v2.png` | 미리보기·백업 (254 dpi) |
| `tag36h11_id{N}_160mm_A4.pdf` | v1. **쓰지 말 것.** 기록으로만 남긴다 |
| `tag36h11_id{N}_raw.png` | 라벨 없는 순수 태그. 재생성 원본 |

재생성:

```bash
python3 ../tools/make_apriltag_sheets.py --out .
python3 ../tools/make_apriltag_sheets.py --cell-px 200 --suffix v2b   # 160 mm 로
```

스크립트가 A4 넘침과 quiet zone 침범을 자동으로 막는다. 둘 다 실제로 한 번씩
당했다.

## 왜 v2 인가 — v1 이 실인쇄에서 틀어졌다

v1 은 검은 사각형 160 mm + 흰 여백 20 mm = **내용 200 mm** 였다. A4 가 210 mm
이니 좌우 여백이 **5 mm 뿐인데, 프린터의 인쇄 불가 영역이 보통 사방 3~5 mm** 다.
그래서 앱에서 배율 100 % 를 골라도 드라이버가 "인쇄 가능 영역에 맞춤"을 다시
걸었고, 그것도 **축마다 다른 비율**로 걸렸다.

```
2026-08-03 실측:  155.0 x 152.0 mm   (설계 160.0 정사각)
                  가로 96.9 % / 세로 95.0 %
                  종횡비 1.0197 → +2.0 % 왜곡

여백 5 mm 가정 시 예상:  160 x (200/210) = 152.4    가로
                        160 x (287/297) = 154.6    세로
→ 실측과 0.5 mm 이내 일치. 원인 확정.
```

**종횡비 왜곡이 진짜 문제다.** `solvePnP` 는 태그를 정사각형으로 가정하므로,
실제가 직사각형이면 **없는 기울기를 만들어낸다.** 크기 오차는 `tag_size_m` 으로
보정되지만 종횡비는 보정할 방법이 없다.

### v2 가 바꾼 것

| | v1 | v2 |
|---|---|---|
| 검은 사각형 | 160 mm | **140 mm** |
| 한 칸 | 20 mm | 17.5 mm |
| 내용 전체 | 200 mm | **175 mm** |
| 페이지 여백 | 5 mm ← 인쇄 불가 영역과 겹침 | **17.5 mm** |
| 검증 수단 | 없음 (태그를 재서 역산) | **100 mm 검증자 가로·세로** |
| 생성 | 즉석 (재현 불가) | `tools/make_apriltag_sheets.py` |

검출 거리는 그대로다. 140 mm 태그를 2 m 에서 보면 약 79 px 로 잡히고,
tag36h11 은 30~40 px 부터 검출된다.

## 인쇄 후 반드시 할 것

**검증자 막대 두 개(아래 가로 / 왼쪽 여백 세로)의 전체 길이를 잰다.**

| 결과 | 뜻 |
| --- | --- |
| 둘 다 100.0 mm | 배율 정상. `tag_size_m:=0.140` 그대로 |
| 둘 다 같은 값인데 100 이 아님 | 균일 축소. 검은 사각형을 재서 그 값을 넣는다 |
| **두 값이 다름** | **축마다 다른 배율. 다시 뽑아라** — 보정 불가 |

⚠ **한 변만 재면 안 된다.** v1 에서 그렇게 해서 종횡비 왜곡을 놓쳤다.

검은 사각형도 가로·세로 둘 다 잰다.

```bash
ros2 launch robot_bringup tag_drive.launch.py tag_size_m:=0.140
```

## 태그 배치

| ID | 위치 | 마주보는 방향 |
| ---: | --- | --- |
| **1** | 충전스테이션 | 복귀 진입 방향 |
| **2** | 코너 · 면A | **출발**(1→2→3) 진입 방향 |
| **3** | 도착지 | 출발 진입 방향 |
| **4** | 코너 · 면B | **복귀**(3→2→1) 진입 방향 |

코너는 2면 기둥이다. 출발 때와 복귀 때 진입 방향이 90° 다르므로 면이 두 개
필요하고, 서로 다른 ID 를 주면 상태머신이 "지금 어느 방향에서 접근 중인지"를
검증할 수 있다.

## 치수

254 dpi 를 쓴다. `254 / 25.4 = 10` 이므로 **1 px = 정확히 0.1 mm** 다.
300 dpi 는 1 px = 0.0847 mm 라 160 mm 를 정수 픽셀로 만들 수 없다.

```
한 칸               200 px = 20.0 mm
검은 사각형 (8칸)   1600 px = 160.0 mm     ← 설정에 넣는 값
흰 여백 포함 (10칸) 2000 px = 200.0 mm
A4 페이지           2100 × 2970 px = 210.0 × 297.0 mm
```

검증 결과 (생성 직후 실측):

```
PDF MediaBox        210.00 × 297.00 mm   (4장 전부)
검은 사각형 픽셀     x 250~1849, y 350~1949  = 1600 × 1600 px = 160.0 × 160.0 mm
OpenCV 재검출        ID 1→1, 2→2, 3→3, 4→4  일치
```

## 인쇄 설정

- **배율 100%**. "용지에 맞춤"·"축소해서 인쇄" 를 반드시 끌 것 — 이게 켜져
  있으면 크기가 달라지고, 크기 오차는 그대로 거리 오차가 된다
- **흰 여백을 자르지 말 것.** 검은 사각형 바깥 1칸(20 mm)의 흰 여백은 검출에
  필수다. 색 판에 붙일 때도 이 영역은 흰색으로 남긴다
- **인쇄 후 검은 사각형 바깥 변을 자로 재서 그 값을 설정에 넣는다.** 프린터
  배율 때문에 160.0 mm 가 정확히 나오지 않는다. 10% 틀리면 거리도 10% 틀린다
- 무광 라미네이팅. 광택은 반사로 검출을 실패시킨다
- 평평한 판에 부착. 휘면 pose 가 틀어진다

## 장착

- **수직으로 세운다.** 바닥에 눕히면 전방 카메라 기준 사각이 82° 가 되어
  1.5 m 에서 화면상 23 px 로 눌린다 (수직이면 177 px). 검출 한계까지 떨어지고
  pose 는 쓸 수 없다
- **태그 중심 높이 = 카메라 높이.** 수직 화각이 30° 뿐이라 높이가 어긋나면
  근접 시 프레임을 벗어난다
- 법선이 진입 방향을 정면으로 마주보게
- 받침대는 바람에 안 넘어갈 무게. 태그가 기울면 그만큼 pose 가 틀어진다

## 검출 가능 거리 (160 mm 태그, Brio 100)

| 해상도 | 60 px (pose 안정) | 40 px (실용 한계) |
| --- | --- | --- |
| 1280×720 (f=1325 px) | 3.5 m | 5.3 m |
| **1920×1080 (f=1988 px)** | **5.3 m** | 8.0 m |

최소 거리는 0.5 m. 고정초점이라 0.4 m 이내는 흐려지고, 수직 화각 30° 때문에
0.3 m 에서는 160 mm 태그가 프레임을 넘친다.

1080p 의 프레임률이 21.6 fps 로 720p(22.4 fps)와 거의 같으므로 **1080p 권장**.

## 설정에 넣을 값

```yaml
family: 36h11
max_hamming: 0
detector: { threads: 4, decimate: 1.0, blur: 0.0, refine: true }
tag:
  ids:    [1,          2,           3,         4]
  frames: [tag_dock,   tag_corner_a, tag_goal,  tag_corner_b]
  sizes:  [0.160,      0.160,       0.160,     0.160]   # 실측값으로 교체
```

`detector.decimate` 기본값은 **2.0** 이다. 그대로 두면 절반 해상도로 검출해서
검출거리가 반토막 난다. 반드시 **1.0** 으로 바꾼다.

`tag.ids` 는 optional 이라 **선언하지 않은 ID 도 검출된다.** ID 화이트리스트는
소비 노드에서 따로 걸어야 한다.
